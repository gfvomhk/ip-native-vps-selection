## 什么是原生IP？和广播IP、家宽IP差在哪

原生IP指IP段的注册归属地和机房实际位置一致：机房在日本，IP也注册在日本运营商名下，这才叫原生。广播IP（中转IP）则是IP注册在A地、实际从B地对外广播，你买到的是“美国VPS”，IP注册信息却指向别处，平台核查归属时看到的就是错位数据。

家宽IP（住宅IP）是另一个维度：IP注册在真实ISP名下，比如美国的AT&T、Comcast、Verizon，越南的Viettel、VNPT，在IP信誉库里被标注为"residential"或"fixed broadband"。从目标平台的角度看，你的流量和一个普通家庭宽带用户没有区别。

所以买之前要分开问两个问题：归属地是否一致（原生还是广播），注册身份是机房还是住宅。不少宣传话术就是靠把这两个维度搅在一起唬人的。

## 下单前怎么验证IP是不是真原生

验证靠工具加实测，两步就能确认。

第一步，查数据库。拿到IP后去Scamalytics、IPinfo这类工具查风险分和IP类型：独立纯净的IP风险分应该接近0；IPinfo里的使用类型应该是"residential"或"fixed broadband"；IP注册地要和机房位置对得上。商家页面上写的“原生”“住宅”不作数，数据库标注才算数。

第二步，警惕伪独立。有些商家宣传“独立IP”，实际是NAT后分给你的伪独立，公网看到的还是共享IP。查一下IP的ASN归属，如果落在普通托管商的大段地址里，共享风险就高。

数据库都过了，最后用真实业务验证——把IP接到TikTok、Netflix或你的目标服务上跑一跑，看会不会弹验证、能不能解锁。LisaHost标准VPS有48小时无理由退款，美国CN2 GIA还有2元/1天的试用，验证成本几乎可以忽略。👉 [先用2元试用测一天美国CN2 GIA家宽节点](https://bit.ly/lisaHost)

## 常见问题

**原生IP和独立IP是一回事吗？**

两者是不同维度的概念。独立IP说的是独占——这个IP只有你在用；原生IP说的是归属——IP注册地与机房所在地一致。一个IP可以两者兼得，也可以只满足其一，买之前分别确认。

**怎么判断商家给的IP是不是真原生？**

用Scamalytics查风险分，越接近0越好；用IPinfo查IP类型和注册地，确认注册地与机房位置一致、使用类型为住宅或家宽。页面宣传词不作为判断依据。

**买了发现IP不行怎么办？**
